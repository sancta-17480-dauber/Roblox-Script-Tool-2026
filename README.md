## FAQ

### Is XCutors safe to use?

XCutors is a toolset for running authorized scripts. We recommend using it in a secure, offline environment and reviewing all scripts before execution.

### What Windows versions are supported?

XCutors is designed for and tested on Windows 10 and Windows 11.

### Do I need to install all executors?

No. The universal loader allows you to choose and use any single executor from the pack. You can use Volt, Synapse Z, Potassium, or Wave individually.

### How do I update the executors?

Simply download the latest release package and replace the files in your installation folder. The loader will detect the updates.

### Can I run scripts for any Roblox game?

Script compatibility depends on the game's security systems and the script itself. XCutors provides the environment; success varies by game.

### Where can I find scripts to use?

There are many community forums and script repositories online. Always source scripts from trusted developers.

### Does this require a license or key?

XCutors itself is a free loader. The included executors (like Synapse Z) may have their own separate licensing or key systems which you must obtain legitimately.
